## Problem Statement

<sub>This problem is a programming version of [Problem 10](https://projecteuler.net/problem=10) from [projecteuler.net](https://projecteuler.net/)</sub>


The sum of the primes below $10$ is $2 + 3 + 5 + 7 = 17$.

Find the sum of all the primes not greater than given $N$.

## Input Format

The first line contains an integer $T$ i.e. number of the test cases.

The next $T$ lines will contains an integer $N$.

## Output Format

Print the value corresponding to each test case in separate line.

## Constraints

+ $1 \leqslant T \leqslant 10^4$

+ $1 \leqslant N \leqslant 10^6$

## Sample Tests

```
2
5
10
```

### Test 2

```

```
