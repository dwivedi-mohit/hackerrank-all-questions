## Preview

Identify the winning Tic-Tac-Toe game using regex.

## Problem Statement

You are given a string containing exactly $9$ characters. 


- The first three characters represent the values in the top row of tic-tac-toe.

- The next three characters represent the values in the middle row of tic-tac-toe.

- The last three characters represent the values in the last row of tic-tac-toe.

The characters used are __`X`__, __`O`__ and __`-`__ only.

$$Tic-Tac-Toe$$

Your task is to write a regular expression that identifies a winning game of tic-tac-toe.
