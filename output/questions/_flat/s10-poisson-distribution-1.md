## Problem Statement

**Objective**	
In this challenge, we learn about Poisson distributions. Check out the [Tutorial](/challenges/s10-poisson-distribution-1/tutorial) tab for learning materials!

**Task**	
A random variable, $X$, follows Poisson distribution with mean of $2.5$. Find the probability with which the random variable $X$ is equal to $5$.

## Input Format

The first line contains $X$'s mean. The second line contains the value we want the probability for:

	2.5
    5
  

If you do not wish to read this information from stdin, you can hard-code it into your program.

## Output Format

Print a single line denoting the answer, rounded to a scale of $3$ decimal places (i.e., $1.234$ format).
