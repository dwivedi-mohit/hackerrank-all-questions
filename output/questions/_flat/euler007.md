## Preview

Finding the Nth prime.

## Problem Statement

<sub>This problem is a programming version of [Problem 7](https://projecteuler.net/problem=7) from [projecteuler.net](https://projecteuler.net/)</sub>

By listing the first six prime numbers: $2, 3, 5, 7, 11$ and $13$, we can see that the $6^{th}$ prime is $13$. 

What is the $N^{th}$ prime number?

## Input Format

First line contains $T$ that denotes the number of test cases. This is followed by $T$ lines, each containing an integer, $N$.

## Output Format

Print the required answer for each test case.

## Constraints

+ $1 \leqslant T \leqslant 10^3$

+ $1 \leqslant N \leqslant 10^4$

```

3
6
```
