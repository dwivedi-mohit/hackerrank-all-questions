## Preview

Calculate the expected count of leaves in a random tree generated by a specified algorithm.

## Problem Statement

Anna loves studying *trees* (i.e., undirected acyclic connected graphs). She even invented the following algorithm to randomly generate a tree with $n$ vertices: 

1. Initially, we have a positive integer, $n$, and a tree with one vertex (numbered $1$).
2. Next, we add vertices $2, 3, \ldots, n$ one at a time. To add each vertex $i$ (where $2 \le i \le n$), we create edge $(x, i)$ where $x$ is randomly chosen from the previously-added vertices (i.e., vertices in the inclusive range from $1$ to $i - 1$).

We define a *leaf* to be a vertex whose degree (i.e., number of connected edges) is exactly $1$. Note that vertex $1$ is considered to be the root, so it's *never* counted as a leaf.

Given the number of vertices in the tree, help Anna by finding the [expected](https://en.wikipedia.org/wiki/Expected_value) number, $E$, of leaves in the tree. Then print the value of $(E \times n!) \bmod (10^9 + 7)$ as your answer.

## Input Format

A single integer, $n$, denoting the number of vertices in the tree.

## Output Format

Print the value of $(E \times n!) \bmod (10^9 + 7)$, where $E$ is the [expected](https://en.wikipedia.org/wiki/Expected_value) number leaves in the generated tree.

## Constraints

- $2 \le n \le 10^5$
