## Preview

Pandigital Prime

## Problem Statement

<sub>This problem is a programming version of [Problem 41](https://projecteuler.net/problem=41) from [projecteuler.net](https://projecteuler.net/)</sub>


We shall say that an $n$-digit number is pandigital if it makes use of all the digits 1 to $n$ exactly once. For example, $2143$ is a $4$-digit pandigital and is also prime.


What is the largest $n$-digit pandigital prime $\le N$? If there is none, print -1

## Input Format

First line contains $T$ that denotes the number of test cases. This is followed by $T$ lines, each containing an integer, $N$.

## Output Format

Print the required answer for each test case.

## Constraints

$1 \le T \le 10^5$

$10	\le N \le 10^{10} - 1$
