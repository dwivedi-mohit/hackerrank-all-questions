## Problem Statement

Welcome to Day 10! Check out [this video](https://youtu.be/8WW9vdd421s) for a review of *binary numbers*, or just jump right into the problem. 

For this challenge, convert a given number, $n$, from decimal (base $10$) to binary (base $2$).

## Input Format

The first line contains a single integer, $T$, the number of test cases. 
The $T$ subsequent lines of test cases each contain a single value, $n$, the base $10$ positive integer to be converted.

**Constraints**		
$1 \le T \le 1000$  	
$1 \le n \le 2^{31}$

## Output Format

For each test case, print the value of $n$ in binary on a new line.
