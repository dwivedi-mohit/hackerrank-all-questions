## Problem Statement

Welcome to Sevenkplus' perfect math class! In this class we study topological spaces.

A **topological space** is an ordered pair $(X, O)$ where $X$ is a set and $O\subseteq 2^X$ (i.e. $O$ is a set of subsets of $X$) satisfying the following axioms: 

1. $\emptyset\in O$, $X\in O$.
2. For any set $I$ and map $f:I\to O$, we have $\bigcup_{i\in I} f(i)\in O$.
3. For any finite set $I$ and map $f:I\to O$, we have $\bigcap_{i\in I} f(i)\in O$.

Elements in $O$ are called **open sets**. $O$ is called a **topology**.

A **subbasis** of a topological space $(X,O)$ is a set $U\subseteq O$ such that if $(X,O^\prime)$ is a topological space and $U\subseteq O^\prime$, then $O\subseteq O^\prime$.

Given $X$ and a set $U\subseteq 2^X$, there is a unique $O\subseteq 2^X$ such that $U$ is a subbasis of the topological space $(X,O)$. $O$ is called the **topology generated by $U$**.

Now, let us have a small test. Let $X=\{1,\ldots,n\}$. You are given a set $U\subseteq 2^X$ such that all elements in $U$ are in the form $\{L,L+1,\ldots,R\}$ for some $L$, $R$. Calculate the cardinality of the topology generated by $U$.

Since the answer may be very large, you should output it modulo $10^9+7$.

**Note**: Here we only give the definitions but not explanations or examples that provide intuition. For examples and explanations of the defintions, you can refer to Wikipedia or any introductory point set topology book. Our definitions are the same (or at least equivalent to) the definitions in mathematics. The defintions given here suffice for solving this problem.


**Input Format**

The first line is $T$, the number of test cases.
Following are $T$ test cases.

For each test case, first line, $n$, $m$. $n$ is the cardinality of $X$ and $m$ is the cardinality of $U$.
Following are $m$ lines. Each line contains two numbers, $L$ and $R$, which means that an element in $U$ is $\{L,L+1,\ldots,R\}$.

**Constraints**

Sum of all $n\le 10000$. 

Sum of all $m\le 100000$. 

$n, m > 0$, $1\le L\le R\le n$.

For each test case, each pair $(L, R)$ occur at most once.


**Output Format**

$T$ lines. Each line is the answer to the corresponding test case.


**Sample Input**


	1
    3 2
    1 2
    2 3

**Sample Output**


	5

**Explanation**

The topology generated by $U$ is $\{\{\}, \{1,2\}, \{2\}, \{2,3\}, \{1,2,3\}\}$.
