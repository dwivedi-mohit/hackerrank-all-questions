## Problem Statement

<sub>This problem is a programming version of [Problem 39](https://projecteuler.net/problem=39) from [projecteuler.net](https://projecteuler.net/)</sub> 


If $p$ is the perimeter of a right angle triangle with integral length sides, {a, b, c}, there are exactly three solutions for $p = 120$

$\{20,48,52\}, \{24,45,51\}, \{30,40,50\}$

For which value of $p \le N$, is the number of solutions maximised? If there are multiple values print smallest.

## Input Format

First line contains $T$ that denotes the number of test cases. This is followed by $T$ lines, each containing an integer, $N$.

## Output Format

Print the required answer for each test case.

## Constraints

$1 \le T \le 10^5$

$12	\le N \le 5\times10^{6}$
