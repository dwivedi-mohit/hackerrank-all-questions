## Preview

You need to determine whether the contest problems set is balanced or not.

## Problem Statement

Devu has proposed $5$ problems to Wanbo for **Hack 101 July**. Wanbo gave his feedback on every problem as a pair of two numbers (**Beauty** and **Difficulty**).


Devu believes that the contest is balanced if there exsists an ordering of five problems such that the **Beauty** value strictly increases and the **Difficulty** value also strictly increases. 


You will be given the feedback of Wanbo and you need to decide whether the contest is balanced or not.


Print $1$ if the contest is balanced; otherwise print $0$.

## Input Format

There will be $5$ lines in the input. 

Each line contains two integers, **Beauty** and **Difficulty**, which represent the feedback to a problem given by Wanbo.

## Output Format

Print $1$ if the contest is balanced; otherwise print $0$.

**Constraints**

$1 \le$ **Beauty** $\le 10$

$1 \le$ **Difficulty** $\le 10$
