## Problem Statement

Jimmy puts Ann's birthday present in a [cuboid](https://simple.wikipedia.org/wiki/Cuboid) box. The dimensions of its edges are positive integers and the sum of its $length$, $width$, and $height$ is $N$. 

What is the *maximum volume* Ann's present box can have? 

<img src="https://s3.amazonaws.com/hr-challenge-images/16240/1453321454-a046e276b4-ann.png" title="ann.png" />

$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \   length + width + height = N$

## Input Format

A single integer, $N$ (the sum of the box's $length$, $width$, and $height$).

**Constraint**<br>
$3 \le N \le 10^3$<br>

## Output Format

Print the *maximum possible volume* of the box. <br>

**Sample Input 0**

	4
    
**Sample Output 0**

	2
    
**Sample Input 1**

	8
    
**Sample Output 1**

	18
