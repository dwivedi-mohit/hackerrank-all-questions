## Problem Statement

Sofi received an array of integers, $A$, as a birthday present, and decides to cut it into segments. She wants to know how many different cuttings have segments with products divisible by her favorite number, $K$. Help her find the answer, and print it modulo $10^9+9$.

**Constraints**<br>
$1 \le N \le 10^5$<br>
$2 \le K \le 10^{18}$<br>
$1 \le A_i \le 10^{18}$<br>

## Input Format

The first line contains two space-separated integers, $N$ (the size of Sofi's array) and $K$ (Sofi's favorite number).<br>
The second line contains $N$ space-separated integers describing Sofi's array ($A$).<br>

## Output Format

Print the number of different cuttings with segment products that are divisible by $K$ modulo $10^9+9$.
