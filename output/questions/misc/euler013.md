## Preview

## Problem Statement

<sub>This problem is a programming version of [Problem 13](https://projecteuler.net/problem=13) from [projecteuler.net](https://projecteuler.net/)</sub>


Work out the first ten digits of the sum of $N$ $50-digit$ numbers.

## Input Format

First line contains $N$, next $N$ lines contain a 50 digit number each.

## Output Format

Print only first 10 digit of the final sum

## Constraints

+ $1 \leqslant N \leqslant 10^3$
