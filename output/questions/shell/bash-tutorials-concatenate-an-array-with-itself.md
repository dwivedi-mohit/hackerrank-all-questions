## Preview

Concatenate an array with itself.

## Problem Statement

Given a list of countries, each on a new line, your task is to read them into an array. Then, concatenate the array with itself (_twice_) - so that you have a total of three repetitions of the original array - and then display the entire concatenated array, with a _space_ between each of the countries' names.

**Recommended References**

Here's a [great tutorial](http://www.thegeekstuff.com/2010/06/bash-array-tutorial/) tutorial with useful examples related to arrays in Bash.

## Input Format

A list of country names.
The only characters present in the country names will be upper or lower case characters and hyphens.

## Output Format

Display the entire concatenated array, with a _space_ between each of them.
