## Problem Statement

Consider the following binary image where $0$ is the background, and $1$ represents a pixel on an object.  

	000110001010
    111011110001
    111010010010
    100000000100 
    

If we segment this image on a model based on simple **4 pixel connectivity**, how many 4-connected objects do you obtain? 
Enter the appropriate integer in the text box below.  
Alternatively, you may submit a program which computes and displays the required integer.
