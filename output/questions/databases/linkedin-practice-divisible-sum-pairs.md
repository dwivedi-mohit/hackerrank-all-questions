## Problem Statement

You are given an array of $n$ integers, $a_0, a_1, \ldots, a_{n-1}$, and a positive integer, $k$. Find and print the number of $(i, j)$ pairs where $i \lt j$ and $a_i$ + $a_j$ is evenly divisible by $k$. 

## Input Format

The first line contains $2$ space-separated integers, $n$ and $k$, respectively.	
The second line contains $n$ space-separated integers describing the respective values of $a_0, a_1, \ldots, a_{n-1}$.



## Output Format

Print the number of $(i, j)$ pairs where $i \lt j$ and $a_i$ + $a_j$ is evenly divisible by $k$.

## Constraints

* $2 \leq n \leq 100$
* $1 \leq k \leq 100$
* $1 \leq a_i \leq 100$
