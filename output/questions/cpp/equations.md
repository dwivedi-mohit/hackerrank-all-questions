## Problem Statement

Find the number of positive integral solutions for the equations 
$$\frac{1}{x} + \frac{1}{y} = \frac{1}{N!}$$
    
**Input Format**  
An integer N   

**Output Format**  
The number of positive integral solutions for the above equation modulo 1000007  

**Constraints**  
$1 \le N \le 10^6$
