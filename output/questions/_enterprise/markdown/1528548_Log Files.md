## Problem Statement

In a Microsoft Windows operating environment, a more complex challenge arises that requires meticulous attention. This involves the reorganization and relocation of multiple log files generated by system applications, distributed across various folders in a common directory named LogFiles. Each of these log files bears a distinctive name that reflects the timestamp of their creation, represented in the format Log_YYYYMMDD_HHMMSS.log.

The main task consists of orchestrating these files based on the embedded timestamp in their names, and then moving them to a separate specific folder labeled SortedLogFiles. This must be done without altering their original file names.
