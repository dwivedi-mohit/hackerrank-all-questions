## Summary

This multiple choice question evaluates Azure Blob Storage, SAS token management, and performance optimization concepts, ideal for senior-level roles. The problem requires identifying an approach to reduce SAS token generation calls during peak traffic without compromising security.

## Problem Statement

An enterprise-grade, high-traffic Azure web app uses Azure Blob Storage for frequent document access. The web app uses SAS tokens for blob access, with Storage Service Encryption enabled. During peak traffic periods, application performance degrades due to the high volume of SAS token generation calls to the Azure Storage REST API.

Which of the following approaches alleviates this issue without affecting security or direct blob access?
