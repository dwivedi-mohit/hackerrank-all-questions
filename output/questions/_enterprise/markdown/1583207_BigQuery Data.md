## Problem Statement

A financial institution is using BigQuery to analyze vast amounts of transactional data. They must improve query performance and control the costs of a table that contains data about customer transactions. It has the following columns: `customer_id`, `transaction_id`, `transaction_date`, `transaction_amount`.

The objective is to efficiently retrieve transaction information for a specific customer from the table.

 

Which method best accomplish this goal?
