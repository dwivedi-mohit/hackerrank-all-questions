## Problem Statement

A fintech company using a multi-tiered application architecture must manage both its transaction processing and user management servers. Due to regulatory requirements, any software updates on the transaction servers must be mirrored on the user management servers within a specified time. The application offers a REST API endpoint that indicates the version of the software package installed on each server.

Given this scenario, which of the following Ansible playbooks correctly ensures synchronization between the two sets of servers using the provided REST API?
