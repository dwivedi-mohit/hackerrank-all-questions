## Problem Statement

An API is offered in three subscription tiers: Free, Standard, and Premium. Each tier has different rate limits. Free users can make up to 100 requests per hour, Standard users get 500 requests per hour, and Premium users have no limit. 

 

How should rate limiting be implemented on Apigee based on the subscription tiers, assuming these tiers have their own API Products - FreeTierProduct, StandardTierProduct and PremiumTierProduct?
