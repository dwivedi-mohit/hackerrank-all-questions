## Summary

This multiple choice question evaluates network security, cloud security, and incident response concepts, ideal for mid-level roles. The problem requires determining the appropriate action to take in response to malicious activity affecting server performance despite firewall protections.

## Problem Statement

Your company is in the fashion business.  As your designers release their new collections, customers complain about slow response times.  Unusual errors like “WebPage not responding” and “Service unavailable” occur intermittently. After checking the logs, you realize that malicious activity is the cause. This is unexpected because the server is protected by a firewall that allows only 80/443 inbound. You are under huge pressure and need to act quickly. What would you do?
