## Problem Statement

A data engineering team needs to optimize a Cloud Dataproc cluster to run Apache Spark SQL jobs over large Parquet files in Cloud Storage. The cluster needs to be cost-effective and use preemptible virtual machine (VM) instances to minimize cost. The solution will dynamically allocate resources to optimize frequent data shuffling. It must allow secure access to the Spark user interface for debugging purposes without exposing it to the public internet.
