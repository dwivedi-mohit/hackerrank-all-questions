## Summary

This multiple choice question evaluates Salesforce Record Triggered Flow, account management, and opportunity updates concepts, ideal for mid-level roles. The problem requires determining the outcome of a flow that updates Opportunity Stage based on changes to an Account's Status field.

## Problem Statement

A business in Salesforce has the following setup.

 

	
- Account has custom picklist field with API name as Status__c and field possible values are:

	
		
- Active
		
- Inactive
	
	

 

The business requirement is to update all related Opportunity Stage to a custom value Account Updated for an Account when the Account Status is changed.

 

For the implementation in Salesforce, an admin has created a Record Triggered Flow on the Account object with trigger condition as A record is updated.

 

What is the result of the flow?
