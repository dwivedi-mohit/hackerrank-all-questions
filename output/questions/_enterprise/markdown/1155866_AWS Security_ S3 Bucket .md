## Summary

This multiple choice question evaluates AWS KMS permissions, multipart uploads, and S3 bucket configurations, ideal for senior-level roles. The problem requires identifying reasons for an Access Denied error when uploading large files to S3 with KMS encryption.

## Problem Statement

A developer runs a shell script that uses the AWS CLI to upload a large file to an S3 bucket with an AWS KMS key. An Access Denied is returned whenever the developer tries to upload a file with a size of 100 GB or more. When uploading a smaller file with the KMS key, the upload succeeds.

Which of the following are possible reasons why this issue is happening? (Select TWO.)
