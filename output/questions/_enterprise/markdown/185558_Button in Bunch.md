## Summary

This HTML/CSS/JavaScript question evaluates DOM manipulation, event handling, and user interaction concepts, ideal for junior-level roles. The problem requires creating buttons that alert their respective indexes when clicked.

## Problem Statement

Add 20 buttons to the page arranged in a row, with indexes 1, 2, 3, ..., 20. Clicking on a button should alert its index. For example, clicking on the first button (the leftmost) should alert 1, and clicking on the last button (the rightmost) should similarly alert 20.
