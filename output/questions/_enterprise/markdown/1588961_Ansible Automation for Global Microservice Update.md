## Problem Statement

A global software company has recently adopted a microservices architecture. The microservice responsible for user authentication needs an urgent security update. It can be put into maintenance mode through its REST API to ensure that no new user authentications are processed while allowing ongoing sessions to continue. The API also provides endpoints for health checks and functionality tests. The requirement is to automate the update process, ensuring zero downtime and that the service remains functional post-update.

Using Ansible, which is the best approach?
