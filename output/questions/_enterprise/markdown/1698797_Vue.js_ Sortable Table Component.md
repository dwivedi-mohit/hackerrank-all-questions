## Problem Statement

Sortable Table Component

Create a Vue.js application that fetches data from an API and displays it in a table. The table should have sorting functionality based on different columns.

The component has the following functionalities:

	
- When the screen loads, it pulls data from an API and presents it in a table format. The URLs to be fetched are provided, as well as the columns to be displayed.
	
- The App component passes table data to the HTable component.
	
- The HTable component should have sorting functionality based on different columns.
	
- The sorting direction can be changed by toggling the column.

 

The following data-testid attributes are required in the component for the tests to pass:

	
- 
	
The table header rows `<th>` in the HTable component should have the data-testid attribute 'header'.

	
	
- 
	
The table body rows `<tr>` containing the user data should have the data-testid attribute 'users'.

	
	
- The table data `<td>` containing the data of each user should have the data-testid attribute 'user'.
	
 

	

Please note that the component has these data-testid attributes for test cases and certain classes and ids for rendering purposes. It is advised not to change them.
