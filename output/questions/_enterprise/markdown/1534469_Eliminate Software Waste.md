## Problem Statement

A software development team is implementing Lean principles to improve its development process. One of the Lean principles is identifying and mapping the value stream. The team wants to enhance customer value by reducing waste and focusing on continuous improvement. Waste refers to activities that do not contribute value to the end customer.

 

Which of the following is not considered a waste?
