## Summary

This coding question evaluates string manipulation, stack usage, and problem-solving concepts, ideal for junior-level roles. The problem requires determining the minimum number of swaps to balance a sequence of brackets.

## Problem Statement

Given a string brackets consisting only of '(' and ')', determine the minimum number of swaps required to make the sequence balanced.

	
- A sequence is balanced if every opening bracket '(' has a corresponding closing bracket ')'.
	
- A swap can be performed between any two positions in the string (they do not have to be adjacent).
	
- If it is not possible to balance the string using swaps, return -1.

 

Example 1

Suppose brackets = ")()(())(".

Output: 1

 

Swap the characters at the first and last index to get "(()(()))" which is balanced.

 

Example 2

Suppose brackets = "()())".

Output: -1

 

Constraints

	
- 1 ≤ length of the string brackets ≤ 105

	
- 
brackets consists of ')' and '(' only.
