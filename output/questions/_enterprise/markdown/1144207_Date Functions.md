## Summary

This multiple choice question evaluates date functions, calculated fields, and Tableau concepts, ideal for senior-level roles. The problem requires creating a calculated field to determine the first day of the quarter for a given date.

## Problem Statement

You have to create a calculated field that will show the first day of the quarter corresponding to a date field. Which date function(s) satisfy the requirement?

 

For example, if you are given '10-11-2021', the calculated field should return '01-10-2021'.
