## Problem Statement

HackerProduce is involved in manufacturing slabs for construction requirements. Sometimes as a result of errors, some of the slabs produced have cracks which makes them unfit for sale.

 

They want an automated system that can identify the cracked defective slabs. Given a dataset containing both defective and non-defective slabs, build a deep neural network using TensorFlow that can identify the defective products.

 

Files

	
- train.csv
	
- test.csv
	
- sample_submission.csv

 

 

Problem

Build a deep neural network that can identify defective products.

 

For each record in the test set (test.csv), predict the value of the label variable. Submit a CSV file with a header row and one row per test entry. The file (submissions.csv) should have exactly 2 columns:

	
- img
	
- label (Positive - Defective,  Negative - Non-Defective)

 

Evaluation Metric:

The metric used for evaluating the performance of the model is Accuracy:

Accuracy = (Correct Predictions)/(Total No. of predictions made)
