## Summary

This multiple choice question evaluates algorithms, complexity analysis, and problem-solving concepts, ideal for mid-level roles. The problem requires determining the time complexity of a code snippet that doubles a variable until it reaches a specified limit.

## Problem Statement

Consider the following code snippet:

`int a = 1;

while (a < n) {
    a = a * 2;
}`
```

What is the complexity of the above code snippet?
