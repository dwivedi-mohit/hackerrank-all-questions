## Summary

This multiple choice question evaluates boundary testing, testing techniques, and financial transaction concepts, ideal for mid-level roles. The problem requires identifying a valid boundary-testing case for a money transfer feature on a banking website.

## Problem Statement

On a banking website, a user can transfer money from one account to another. The money transfer feature has the following description.

	
- The user can move cash up to 3 times per day.
	
- The money transfer fee for each time is $30.
	
- The maximum total amount for money transfer per day is $30000 including fees.
	
- The transferred money amount must exceed the money transfer fees each time.

Which one of the following options can be used as a boundary-testing case?
