## Summary

This multiple choice question evaluates React Native, useEffect, and state management concepts, ideal for senior-level roles. The problem requires identifying the correct approach to ensure a component re-fetches user data when the userID prop changes.

## Problem Statement

In a production-level React Native app, there is a scenario where a component responsible for fetching and displaying user data is not updating as expected after the user's data changes on the server. The component is intended to fetch new user data when the userID prop changes. Which of the following approaches correctly ensures that the component will re-fetch the user data when the userID changes?
