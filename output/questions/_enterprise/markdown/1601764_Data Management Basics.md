## Summary

This multiple choice question evaluates data compliance, credential management, and security best practices concepts, ideal for mid-level roles. The problem requires identifying best practices for managing credentials to ensure compliance and mitigate security risks in a financial consultancy setting.

## Problem Statement

A data management specialist in a financial consultancy oversees data access for financial analysts. New hires are granted access to business process data and financial activities via secure cryptographic keys stored in a vault. This provides visibility into business operations and comprehensive financial activities.

Given this setup, which best practices should be prioritized for credential management to ensure compliance with industry standards and mitigate security risks?
