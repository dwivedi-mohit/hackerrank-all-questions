This multiple choice question evaluates Spark Streaming, micro-batch processing, and latency reduction concepts, ideal for mid-level roles. The problem requires identifying actions to enhance real-time performance in a Spark Streaming application processing live data streams.

## Problem Statement

A Spark Streaming application ingests live input data streams and divides them into 10-second micro-batches. These micro-batches are processed by the Spark engine to generate the final stream of results. A delay is observed in processing. Which action will directly reduce latency and enhance real-time performance?
