## Problem Statement

An e-commerce company is using Prometheus to monitor its microservices-based architecture. The company wants to use PromQL to create custom queries for data monitoring. Create a custom query that calculates the 95th percentile of request durations for a specific service over the past hour. Exclude any requests that returned an error.
