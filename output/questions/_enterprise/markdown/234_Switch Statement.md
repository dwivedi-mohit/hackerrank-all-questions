## Summary

This multiple choice question evaluates basic concepts of C and C++ programming, ideal for junior-level roles. The problem requires determining the final value of a variable after executing a switch statement with arithmetic operations.

## Problem Statement

int x = 5; 
int y = 2; 
char op = '*'; 
switch (op) 
{ 
  default : x += 1; 
  case '+' : x += y; 
  case '-' : x -= y; 
}

After the sample code above has been executed, what value will the variable x contain?
