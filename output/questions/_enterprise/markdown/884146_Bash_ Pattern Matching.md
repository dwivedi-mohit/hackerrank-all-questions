## Problem Statement

Given an array of strings, count the strings that contain at least one uppercase character and output the result to STDOUT.

 

Example: 

my_array = ["FirstWord", "Word2", "thirdword"]

 

The match_uppercase function will return 2 since "FirstWord" and "Word2" each contain an uppercase letter.
