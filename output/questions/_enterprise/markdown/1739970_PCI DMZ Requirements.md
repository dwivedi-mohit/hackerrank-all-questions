This multiple choice question evaluates PCI DSS compliance, network segmentation, and security measures concepts, ideal for mid-level roles. The problem requires identifying the necessary actions for CyberShield Inc. to secure cardholder data effectively.

## Problem Statement

CyberShield Inc., an e-commerce company, processes payment card transactions through its website. To ensure the security of cardholder data, CyberShield has set up its infrastructure with the database server and web server located within the same, secured DMZ network segment. Both servers are on separate physical machines to enhance security measures.

What is required for CyberShield Inc. to meet PCI DSS requirements?
