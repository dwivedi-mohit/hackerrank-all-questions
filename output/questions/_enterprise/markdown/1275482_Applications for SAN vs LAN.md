## Summary

This multiple choice question evaluates storage management, SAN, and NAS concepts, ideal for senior-level roles. The problem requires determining the appropriate storage devices for various applications and data types in a network environment.

## Problem Statement

You are the Storage Administrator for your company. Your network has two types of storage devices, a storage server on a SAN and a NAS server. You will deploy the software and services listed.

 

	
- MS Exchange
	
- New CRM system (Customer Relationship Management)
	
- New Network Shared Drives
	
- HR system that runs MySQL
	
- D2D backups
	
- Video Surveillance Recording Location

 

What would you place on what devices?
