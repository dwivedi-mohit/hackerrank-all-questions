## Problem Statement

A long string is composed of only five letters: A, B, C, D and E.

For the purpose of compressing the string, an encoding scheme is generated for each of these characters, using the Huffman encoding algorithm (based on their individual frequencies of occurrence). Which of these may be a legitimate encoding scheme for the string?
