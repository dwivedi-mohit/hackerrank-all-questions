## Problem Statement

During a security audit of a financial institution's web application, a critical vulnerability was identified. The application, which allows users to update their personal information, was found to be susceptible to an attack where malicious scripts could be embedded in user input fields. These scripts were later executed in the context of other users' sessions, leading to unauthorized account access and transactions. Despite having standard security measures in place, one crucial aspect was overlooked in the application's development and maintenance.

What was this critical oversight?
