## Summary

This multiple choice question evaluates AWS Glue, memory optimization, and data transformation concepts, ideal for senior-level roles. The problem requires identifying a solution that would not alleviate memory constraints during high-volume ETL tasks involving large, unevenly distributed datasets.

## Problem Statement

A data engineering team leverages AWS Glue for a high-volume extract, transform, and load (ETL) task with terabytes of data. Despite several optimizations, some Glue jobs hit memory constraints and fail. Memory usage spikes significantly during certain transformations involving joining two large datasets, one of which is frequently updated and has an unequal distribution of keys.

 

While aiming to maintain the processing speed, which of these solutions would NOT alleviate the memory constraint issue?
