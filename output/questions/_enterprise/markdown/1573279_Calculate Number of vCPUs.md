## Summary

This multiple choice question evaluates Google Cloud Platform, compute engine, and instance management concepts, ideal for junior-level roles. The problem requires calculating the number of vCPUs needed to match the performance of an existing server setup.

## Problem Statement

A popular digital news outlet is transitioning its web processing infrastructure to Google Compute Engine from its existing on-premises cluster of servers. Each of the seven servers has six-core CPUs with Intel Xeon Processor to manage the high web traffic. The aim is to have similar performance on Compute Engine.

How many vCPUs should be allocated to ensure similar processing efficiency?
