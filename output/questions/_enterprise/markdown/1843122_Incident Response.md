This multiple choice question evaluates network security, session hijacking, and XML parsing concepts, ideal for junior-level roles. The problem requires identifying the attack method observed from a payload structure used to modify server responses.

## Problem Statement

During an incident response, a security consultant uncovers a payload used to modify server responses.

 

Given the payload structure <xml><user>&usr;</user><data>&dt;</data></xml> where &usr; and &dt; are defined entities, which attack method is the consultant observing?
