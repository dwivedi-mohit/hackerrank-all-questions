## Summary

This multiple choice question evaluates outlier detection, quartiles, and interquartile range concepts, ideal for junior-level roles. The problem requires identifying outliers in a given data sample based on statistical definitions.

## Problem Statement

Given a small sample, find the number of outliers. A data point is defined as an outlier if it is more than 1.5 times the length of the data set away from either the lower or upper quartiles.

 

Outlier points: less than Q1−1.5×IQR or greater than Q3+1.5×IQR where IQR is Inter Quartile Range and Q1 and Q3 represent first and third quartiles respectively.

 

Sample:

`2,7,8,9,10,13,15,17,34`
