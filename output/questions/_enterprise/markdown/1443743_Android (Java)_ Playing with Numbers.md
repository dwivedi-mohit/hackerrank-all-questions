## Summary

This mobile development question evaluates sorting algorithms, arithmetic mean calculation, and input validation concepts, ideal for junior-level roles. The problem requires creating an app that sorts five numbers and calculates their mean based on user input.

## Problem Statement

Complete a small app that puts five numbers in ascending or descending order and calculates their arithmetic mean, as shown below.

Hide animation Show animation

 

Functionality Requirements

There are five fields numbered 1 to 5. A 1- to 3-digit number must be entered into each field. When Calculate is pressed, the following is shown:

	
- the values in ascending order
	
- the values in descending order
	
- their arithmetic mean

 

All calculations are made and results are shown inside the Calculate method. If the data entered is incorrect, the incorrect_input string is introduced to the following fields: averageMathResultTv, orderedByDescendingResultTv, orderedByIncreasingResultTv.

 

Method descriptions:

	
- 
checkCorrectInput checks the characters entered.
	
- 
isInteger checks that the characters entered are integers.
	
- 
createInputList creates an ArrayList<String> from the completed fields.
	
- 
сalculateAverage calculates the arithmetic mean of the 5 values entered.
	
- 
sortIncrease sorts the numbers in ascending order and displays the result.
	
- 
sortDecrease sorts the numbers in descending order and displays the result.
	
- 
cleanFields clears the input and results fields.
