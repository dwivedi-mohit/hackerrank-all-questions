## Summary

This multiple choice question evaluates Azure Data Factory, ETL operations, and Integration Runtime concepts, ideal for mid-level roles. The problem requires identifying which operation in the ETL process consumes the most computation time based on given daily IR hour requirements.

## Problem Statement

A video streaming platform utilizes Azure Data Factory to manage its data workloads, generating 1 TB of metadata daily. This metadata is extracted from various cloud and on-premises databases, and loaded into Azure Data Lake for further analysis. The ETL process includes data extraction, transformation, and loading operations. Each operation requires different self-hosted Integration Runtime (IR) hours: extraction requires 10 IR hours, transformation requires 20 IR hours, and loading requires 30 IR hours daily.

 

Considering all data operations are conducted within the same Azure region, which of the following operation in the Azure Data Factory ETL process will require the most computation time on a monthly basis?
