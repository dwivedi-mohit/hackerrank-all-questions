## Summary

This multiple choice question evaluates reporting methodologies, analytics, and visualization concepts, ideal for mid-level roles. The problem requires identifying the best approach for compiling and visualizing project progress and metrics in Azure DevOps.

## Problem Statement

The Director of Engineering oversees multiple projects running in parallel within Azure DevOps for a large organization. The directory is required to provide quarterly reports to the board:

	
- Progress of each project against its defined milestones.
	
- Code quality metrics, including issues and technical debt.
	
- Deployment frequency and success rates.

 

Given the volume of data and the need for detailed visualizations, what is the best reporting methodology in Azure DevOps?
