## Summary

## Problem Statement

An e-commerce platform employs an event-driven architecture, where actions trigger events processed by a cloud-based platform using HTTP and AMQP. The system handles millions of events organized across six partitions, improving analytics and user experience. Two consumer groups provide distinct views of the event stream for in-depth analysis. The organization is considering strategies for performance and scalability improvement.

 

Which strategy is least likely to contribute positively to the system's efficiency?
