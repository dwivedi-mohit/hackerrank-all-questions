## Summary

This multiple choice question evaluates Jenkins, WebSocket communication, and network protocols concepts, ideal for mid-level roles. The problem requires determining the optimal setup for a Windows agent to connect with a Jenkins master under specific network constraints.

## Problem Statement

A company mandates Windows OS for software builds. It maintains a 24/7 cloud-based Windows server for live operations. The Jenkins server uses port 8080 for the private VPC. It has a load balancer that permits specific IP addresses to access Jenkins. The load balancer also forwards port 8080 to HTTPS.

How should the Windows agent be set up to connect with the Jenkins master?
