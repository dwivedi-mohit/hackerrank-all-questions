## Problem Statement

A Databricks developer is working with an engineering team to build a new application. The application will process data from various sources, including a MySQL database, a Hive table, and a Delta Lake table.  AutoMerge can be used to merge changes to data in real time, but the developer is not sure how to use it with all of the different data sources that the application will need to access.

How can the Databricks developer effectively utilize AutoMerge to merge changes from multiple data sources the application needs to access?
