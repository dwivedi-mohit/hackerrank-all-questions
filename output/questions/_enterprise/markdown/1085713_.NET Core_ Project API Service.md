## Problem Statement

A company is launching a service to maintain its projects for its users. The service will be a web API layer built using .NET, with an existing prepared infrastructure. Implement two controllers: in ProjectsController, add the DELETE method, and in UsersController, implement the POST, and GET methods, per the guidelines below. Additionally, implement corresponding services for the controllers, and register these services in the Program.cs file to enable Dependency Injection.

Here is an example of a project model JSON object:

{
    id: 5,
    name: "test name",
    isAvailable : true,
    addedDate: "2024-10-04T14:51:20.482699Z"
}

```

Here is an example of a user model JSON object:

{
    id: 5,
    name: "test name",
    projectId: 5,
    addedDate: "2024-10-04T14:51:20.482699Z"
}
```

API Endpoint Descriptions

The service should adhere to the following API format and response codes:

POST api/projects/{projectId}/users:

- Add the user to the given projectId.

- The HTTP response code should be 201 on success.

- For the body of the request, use the JSON example of the user model given above.

- If a project with {projectId} does not exist, return 404.

GET api/projects/{projectId}/users:

- Delete the project with {projectId}.

- The HTTP response code should be 200 on success.

- If a project with {projectId} does not exist, return 404.

DELETE api/projects/{projectId}:

- Delete the project with {projectId}.

- The HTTP response code should be 204 on success.

- If a project with {projectId} does not exist, return 404.

NOTE: You need to add support for Dependency Injection for internal services (UsersService and ProjectsService) in the project Program.cs file.

Example Requests and Responses

POST api/projects/1/users

Example request:

{
    id: 5,
    name: "Alex",
    addedDate: "2024-10-04T14:51:20.482699Z"
}

```

The response code will be 201, and this user is added to the project with ID 1.

GET api/projects/10/users

Example response:

The response code is 200, and when converted to JSON, the response body (assuming that the below objects are all objects in the collection) is as follows:

[
   {
      id: 5,
      name: "Alex",
      addedDate: "2024-10-04T14:51:20.482699Z",
      projectId: 10,
   },
   {
      id: 6,
      name: "Sam",
      addedDate: "2024-10-04T14:51:20.482699Z",
      projectId: 10,
   }
]

```

DELETE api/projects/10

Example response:

Assuming that the project with ID 10 exists, then the response code is 204 and there are no particular requirements for the response body. This causes the project with ID 10 to be removed from the collection. When a project with ID 10 doesn't exist, the response code is 404 and there are no particular requirements for the response body.
