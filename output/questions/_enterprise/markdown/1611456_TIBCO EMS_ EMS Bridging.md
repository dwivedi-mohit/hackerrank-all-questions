This multiple choice question evaluates TIBCO EMS, messaging layers, and bridging techniques concepts, ideal for senior-level roles. The problem requires identifying which consumers will receive a message sent to a bridged Commerce Queue in a distributed messaging application.

## Problem Statement

For a distributed messaging application in TIBCO, EMS is selected at the messaging layer. In order to handle various underlying systems and applications, a bridging technique is being followed as shown.

Here the Commerce Queue is bridged to the Notification Topic, which is further bridged to the Sales Queue.

 

When a message producer sends a message to Commerce Queue, which set of consumer(s) will receive the message?
