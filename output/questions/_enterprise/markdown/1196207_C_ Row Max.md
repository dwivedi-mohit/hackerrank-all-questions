## Summary

This coding question evaluates dynamic memory allocation, multithreading, and array manipulation concepts, ideal for senior-level roles. The problem requires implementing functions to manage a 3D array and determine rows with the most occurrences of 1's.

## Problem Statement

Implement the following functions for a 3D array.

	
- 
allocate_memory(): Dynamically allocate the memory for the 3D array having height h, r rows, c columns using pthreads.
	
- 
take_input(): Assign values to the allocated matrix.
	
- 
Get_all_Rows():
	
		
- For each of the h 2D arrays, find the row with the greatest number of 1's. Break ties with the lowest index row. If there are no 1's, return -1.
		
- Returns: int maxRows[h]
