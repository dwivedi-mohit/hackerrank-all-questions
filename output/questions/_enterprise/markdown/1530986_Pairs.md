## Summary

This coding question evaluates operator overloading, class design, and STL algorithm compatibility concepts, ideal for junior-level roles. The problem requires implementing a C++ class named Pair that supports various operations and algorithms on a collection of Pair objects.

## Problem Statement

Implement a C++ class named Pair that:

	
- Contains two public integer member variables: first and second.
	
- Includes a constructor that takes two integers to initialize the first and second variables.
	
- Is compatible with the std::sort algorithm for sorting a vector/array of Pair objects in reverse order compared to std::pair.
	
- Is compatible with the std::accumulate algorithm to calculate the sum of a vector of Pair objects, where the resulting Pair object has its first and second variables representing the sum of the corresponding variables in the vector.
	
- Is compatible with the std::adjacent_difference algorithm to find the differences between adjacent elements in a vector/array of Pair objects. For std::adjacent_difference, the result should be stored in a vector such that:
	
		
- res[0] = arr[0]
		
- For all indices i where 1 ≤ i < n: res[i].first = arr[i].first - arr[i-1].first and res[i].second = arr[i].second - arr[i-1].second

	
	

 

Example

`vector<Pair> pairs;
pairs.push_back(Pair(1, 4));
pairs.push_back(Pair(2, 4));
pairs.push_back(Pair(2, 3));

// Old order = {{1,4},{2,4},{2,3}}
std::sort(pairs.begin(), pairs.end());
// New order = {{2,4},{2,3},{1,4}}

Pair sum = std::accumulate(pairs.begin(), pairs.end(), Pair(0,0));
// sum = {2+2+1,4+3+4} = {5,11}

vector<Pair> result(3, Pair(0,0));

std::adjacent_difference(pairs.begin(), pairs.end(), result.begin());
// result = {{2,4},{0,-1},{-1,1}}`
