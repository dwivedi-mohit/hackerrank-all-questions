## Problem Statement

This architectural diagram shows a typical web client using AWS services like Amazon S3 and Amazon SNS. The whole service is hosted in the Amazon cloud.

 

Here, the client is either a web application or a native AWS client that uploads files to Amazon S3. The Amazon S3 bucket is configured to send Amazon Simple Notification Service (Amazon SNS) upon receiving files.

 

What needs to be the Amazon SNS topic type if the order in which messages are published and delivered is strictly preserved?
