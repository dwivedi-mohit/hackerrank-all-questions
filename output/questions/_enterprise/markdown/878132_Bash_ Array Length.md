## Problem Statement

Given an array containing elements of various types (such as strings, integers, etc.), write a function that returns the length of the array and prints it to the standard output.

 

Example:

my_array = ["A1", "b2", "C3d", "4", "e"]

 

There are 5 elements in my_array, so print 5 to stdout.
