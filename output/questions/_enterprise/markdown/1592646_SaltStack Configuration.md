This multiple choice question evaluates reactor systems, event handling, and logging concepts, ideal for mid-level roles. The problem requires selecting the best configuration for a Salt Master's Reactor to respond to specific events and maintain execution logs.

## Problem Statement

Consider a reactor system designed to swiftly respond to the custom event update/app. The system administrator's objectives are as follows:

1. Trigger an immediate high state on chosen minion servers when the event occurs.

2. Respond exclusively to the update/app event.

3. Maintain detailed execution logs, using either internal or external tools.

Based on these goals, which configuration approach is most suitable for the Salt Master's Reactor setup?
