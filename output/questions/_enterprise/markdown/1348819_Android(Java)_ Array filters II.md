## Summary

This mobile development question evaluates Android, Java 8, and filtering concepts, ideal for junior-level roles. The problem requires completing an Android app that filters and displays a list of employees based on various parameters.

## Problem Statement

Complete an Android app to show a list of employees based on filter parameters.

Employees can be added to and removed from the list, and various parameters can be set. Also, minimum and maximum salary amounts can be entered and applied as a filter.

There are two array lists: fullEmployeeArrayList and filterEmployeeArrayList. 

- fullEmployeeArrayList contains all the employees in the app. 

- filterEmployeeArrayList shows the list of employees after any filter parameters are applied. It contains the filtered list from fullEmployeeArrayList after execution of the following methods.

 

	
- "insertEmployee" - insert a new employee to the full list
	
- "getAll" -  contains the list of all employees
	
- "getEmployeeEqualName" - contains the list of employees with the exact specified name
	
- "getEmployeeContansPartName" - contains the list of employees with part of the specified name
	
- "getEmployeeMoreThan" - contains the list of employees with salaries greater than the specified minimum value
	
- "getEmployeeLessThan" - contains the list of employees with salaries less than the specified maximum value
	
- "deleteById" - deletes the employee with the specified id
	
- "deleteAll" - deletes all employees
