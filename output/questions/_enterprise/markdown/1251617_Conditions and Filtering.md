## Problem Statement

The UserOrdersTable DynamoDB table is created with the following attributes.

 

	
- Username
	
- OrderId
	
- Amount

 

Username is the partition key and OrderId is the sort key.

 

Which of the following queries will return all the items where Amount is greater than 100?
