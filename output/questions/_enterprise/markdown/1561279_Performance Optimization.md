## Summary

This multiple choice question evaluates Linux process management, CPU affinity, and resource optimization concepts, ideal for mid-level roles. The problem requires determining the best approach to mitigate CPU usage of a multi-threaded application without affecting its functionality.

## Problem Statement

A Linux system administrator discovers that process abc is consumes CPU resources on a server, leading to performance degradation.

The administrator must mitigate the CPU usage without impacting the functionality of the abc process considering these factors.

	
- The abc process runs as a multi-threaded application, and each thread has different CPU usage patterns.
	
- The server hosts other vital applications that must maintain optimal performance.
	
- The abc process requires frequent access to disk I/O, which further affects its CPU usage.
