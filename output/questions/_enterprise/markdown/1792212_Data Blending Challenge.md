## Summary

This multiple choice question evaluates data blending, dashboard development, and data preparation concepts, ideal for mid-level roles. The problem requires determining the best approach to integrate diverse data sources for accurate reporting in Tableau.

## Problem Statement

When building a complex dashboard in Tableau for a medium-sized e-commerce company, data from multiple sources, including real-time sales data, inventory levels, and customer feedback scores must be integrated. Given that the sales data resides in a cloud-based SQL database, inventory levels are managed in an Excel spreadsheet, and customer feedback scores are stored in a NoSQL database, which approach would be most effective for blending these data sources to ensure accurate and up-to-date reporting?
