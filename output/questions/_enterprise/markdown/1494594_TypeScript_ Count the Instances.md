## Summary

This coding question evaluates constructors, static variables, and class instance tracking concepts, ideal for junior-level roles. The problem requires creating a class that counts its instances and provides a method to retrieve that count.

## Problem Statement

Create a class called InstanceCounter that tracks how many instances of itself have been created. This class should include a method named getInstanceCount, which returns the total number of instances created.

 

For example, if 3 instances of InstanceCounter are created in the code stub, then the getInstanceCount method from the InstanceCounter class should return 3.

 

Function Description

Complete the class InstanceCounter in the editor below.

 

Returns

    int: the number of instances of the InstanceCounter class created so far
