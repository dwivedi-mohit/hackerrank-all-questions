## Problem Statement

A .NET developer needs to improve the performance of a data access layer in a .NET application. The current implementation uses Entity Framework to interact with a SQL Server database. One query retrieves a large dataset which causes significant performance issues. The developer decides to replace this query with a stored procedure. Which of the following approaches demonstrates how to execute a stored procedure named 'GetLargeDataset' and map the results to a Plain Old Class Object (POCO class) named 'DatasetItem' using Entity Framework?
