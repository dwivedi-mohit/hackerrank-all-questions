## Problem Statement

Financial consortiums need an application based on Hyperledger Fabric that can process large volumes of transactions in a short time. The application is designed to deal with complex financial instruments and must maintain a high level of security. If the application's chaincode is provided as an external service, how does this help achieving the consortium's goals of scalability and performance?
