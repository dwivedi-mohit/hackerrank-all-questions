## Summary

This multiple choice question evaluates Apex triggers, governor limits, and master-detail relationships concepts, ideal for mid-level roles. The problem requires selecting a trigger implementation that accurately updates the total budget on the Account object when related Projects change.

## Problem Statement

A custom object named Project exists with a master-detail relationship to the standard Account object. The Project object has a custom field named Budget__c. An apex trigger is needed that calculates the total budget of all projects related to an Account and updates the Total_Budget__c field on the Account object whenever a Project is created, updated, or deleted.

 

Which of the following trigger implementations will accomplish this task and avoid hitting governor limits?
